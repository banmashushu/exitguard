- 官方包：`https://www.netdetour.com/mac/NetDetour.dmg`
- Mac 说明：`https://www.netdetour.com/mac/`
- 代理范围主要为 TCP；其他 UDP 应以明确规则阻断，不能假定自动通过同一出口。
- 公开接口可应用 XML 配置、查启用状态、活动连接和错误日志；尚未发现能完整导出当前生效规则的公开接口。不能据此声称已完成规则实时读回证明。
- 尚未执行其 App 或 CLI、未安装系统扩展、未进行飞连共存或失效测试。
- 软件授权费用独立于代理月费。Mac 的试用期限尚未在本轮明确核实，不购买任何授权。

## 安装后才可开展的验收

安装和启用第三方网络扩展会新增系统级网络控制权限，需用户明确同意并完成 macOS 授权。先只针对不携带账号的测试程序配置：

1. 验证只有被选中的测试程序进入指定代理，其他应用保持原有路径。
2. 验证不可达代理、代理连接关闭、管理程序退出后，测试连接是否会直连。
3. 单独检查 IPv4、IPv6、UDP、DNS 和其他 loopback 端口。
4. 检查与飞连同时运行时是否出现连接或 DNS 异常。
5. 静态代理和实际 Claude 客户端就绪后，才测试登录、聊天、上传及辅助进程。

首次测试不主动断开公司 VPN、不覆盖全局规则、不自动把开发版状态改成已保护。若底层组件不满足所需边界，应保留未就绪状态并调整路线，而不是移除检查。
