BEFORE YOU CONNECT

就绪条件

  1. 1
    确认固定公网出口

    Windows 需要固定节点；Mac 需要公司确认网关出口。两台设备可使用各自的 IP。

  2. 2
    选择目标程序与完整进程范围

    包括浏览器和客户端的网络辅助进程；路径或策略变化后必须重新检查。

  3. 3
    安装并验证系统过滤

    需要平台授权。普通本地应用构建不能自行获得系统过滤权限。

本工具减少意外直连和出口漂移；固定出口与系统过滤均不能保证账号不被封禁。

单凭 utun 编号不能证明飞连已连接或固定出口。

固定本地代理 · 专用入口

先在 Clash / Mihomo 配置一个绑定固定单节点的专用 HTTP 监听。本工具只连接该入口，不更改现有策略。

入口必须固定到具体单一节点。应用的 17890 端口与上游的 17891 端口不可相同；节点或公司网关仍需实际提供固定公网 IP。周期探测存在时间窗口。
高级：Clash / Mihomo 只读兼容检查

只访问明确配置的本机监听和控制接口；指定单一叶子节点。通用控制 API 无法证明此代理入口绑定了该节点，因此此模式只做兼容诊断，不能启用保护；保护请用“固定本地代理”专用入口。

目标程序

只有明确列入策略的程序才属于保护范围。系统按可执行文件或应用身份过滤，不按浏览器资料目录区分。

安装或移除系统过滤只能通过明确执行的命令完成。保存此表单不会安装过滤。完整目标列表与系统策略匹配后，才能启用保护。
