ExitGuard 0.2.1 · Mac 原生桌面版
==============================

适用于 Apple 芯片 Mac，macOS 13 或更新版本。
界面使用 MyGo 原生 Go 控件，代理核心与界面在同一进程运行。

安装方式
--------
打开 DMG，将 ExitGuard 拖到 Applications；也可解压 ZIP 后复制 ExitGuard.app。
替换应用前请退出旧版；现有代理和账号仍保存在原用户配置目录。

首次使用
--------
1. 打开“代理设置”，点击“新建”，为新代理填写一个便于区分的名称。
2. 分栏填写协议、服务器 / IP、端口、代理用户名、代理密码和期望出口 IP，点击一次“保存代理”。
   无需认证时账号留空；需要认证时用户名和密码一起填写，不要把账号写进服务器栏。
3. 每份代理独立保存在本机并记住自己的账号。保存或选择条目只进入编辑，不会切换或启动连接。
4. 点击“使用此代理”，到“概览”检查出口，通过后手动启动。切换代理后也需要重新检查和手动启动。
5. 期望 IP 暂不确定时可先留空：保存并使用代理后，到概览测试候选 IP，核对后回设置手动填写并保存。
6. 添加其他代理时重复上述步骤；概览也可选择已保存代理，再点击“使用所选代理”。同一时间仅使用一份。

升级后，原有远程代理配置及其匹配的已保存账号会在首次打开时自动导入。
重新打开应用会恢复当前使用的代理及其已保存账号，仍保持关闭，需要检查后手动启动。
编辑已保存代理时，账号两栏都留空会保留原账号；密码不会回填。更换服务器需替换或明确清除旧账号。
保存当前使用的代理会暂停连接；删除需要确认，删除当前代理也会关闭连接。不会自动切换到另一份代理。

现有配置仍保存在 ~/Library/Application Support/ExitGuard/，安装替换应用不迁移或删除此目录。
代理列表和各自账号保存在 config.json.profiles.json；账户是受文件权限限制的本机明文，仅匹配所属代理，请勿分享此文件或旧凭据文件。
普通代理只处理明确经过它的流量；受控客户端启动不证明系统级防绕行或 Claude Code 完整覆盖。
应用不自动安装系统过滤、改变全局代理/DNS/VPN、注册开机启动或自动更新。

此本地构建使用 ad-hoc 签名，未使用 Developer ID，也未经过 Apple 公证。
完整的系统过滤和真实客户端流量仍需单独验收。
