ExitGuard 0.2.1 · Windows 原生桌面版
==================================

适用系统：Windows 10 / 11，64 位 x64（amd64）。
界面使用 MyGo 原生 Go 控件，无需安装 WebView2 或其他浏览器运行时。

打开方式
--------
便携包：先完整解压，再双击 ExitGuard.exe。
安装包：运行 ExitGuard-Windows-x64-Setup.exe，按向导安装到当前用户目录。
安装不需要管理员权限。组件页的“创建桌面快捷方式”默认勾选，可取消。
完成页的“启动 ExitGuard”默认勾选；点击“完成”时只有勾选才会打开。取消勾选后可从开始菜单打开。
静默安装、安装失败、取消安装及卸载不会打开应用；没有开机启动项。
升级时不选桌面快捷方式会保留现有快捷方式，不会替你删除桌面文件。卸载清理本程序的开始菜单和桌面快捷方式。
主程序、安装器、卸载器、开始菜单和桌面快捷方式使用同一品牌图标。
本版本没有数字签名，Windows 可能显示未知发布者或 SmartScreen 提示。

首次使用
--------
1. 打开“代理设置”，点击“新建”，为新代理填写一个便于区分的名称。
2. 分栏填写协议、服务器 / IP、端口、代理用户名、代理密码和期望出口 IP，点击一次“保存代理”。
   无需认证时账号留空；需要认证时用户名和密码一起填写，不要把账号写进服务器栏。
3. 每份代理独立保存在本机并记住自己的账号。保存或选择条目只进入编辑，不会切换或启动连接。
4. 点击“使用此代理”，再回到“概览”检查出口，通过后手动启动代理。切换代理后也需要重新检查和手动启动。
5. 期望 IP 暂不确定时可先留空：保存并使用代理后，到概览测试候选 IP，核对后回设置手动填写并保存。
6. 添加其他代理时重复上述步骤；概览也可选择已保存代理，再点击“使用所选代理”。同一时间仅使用一份。
7. 将支持代理的客户端指向界面显示的回环 HTTP 代理地址，或使用界面的受控启动入口。

升级后，原有远程代理配置及其匹配的已保存账号会在首次打开时自动导入。
重新打开应用会恢复当前使用的代理及其已保存账号，仍保持关闭，需要检查后手动启动。
编辑已保存代理时，账号两栏都留空会保留原账号；密码不会回填。更换服务器需替换或明确清除旧账号。
保存当前使用的代理会暂停连接；删除需要确认，删除当前代理也会关闭连接。不会自动切换到另一份代理。

配置通常保存在 %APPDATA%\ExitGuard\config.json，代理列表及各自账号在独立的 config.json.profiles.json 文件。
账户记录为本机明文，使用 Windows 文件权限限制访问；不是密码保险箱。
请勿分享凭据文件。安装和卸载不读取、迁移或删除此用户数据目录。
退出或暂停会关闭本程序持有的转发连接；不改变系统网络设置。

功能边界
--------
普通固定出口代理只处理明确经过本机代理的流量，不等于应用或整台电脑禁止绕行。
客户端忽略代理、UDP、其他窗口和辅助进程仍可能使用别的网络路径。
Chrome / Edge 受控启动会传入专用代理参数；现有普通窗口不会自动纳入。
Claude Desktop 发现或进程启动成功不证明其 Code 标签页及全部子进程遵循代理。
本包不包含 CLI、NativeProbe、Sandboxie 或原生沙箱预览脚本，也不安装系统过滤。
界面的 Windows 应用保护试用需要单独部署预览工具与 Sandboxie，当前发行包未提供。
系统级防绕行、WFP / 沙箱、DNS broker 和真实客户端完整流量尚未完成 Windows 验收。
切换普通代理或退出应用不会撤销你以前另行安装的系统过滤规则。
